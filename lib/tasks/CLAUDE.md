# lib/tasks/ — rake 시드 태스크

'책갈피'의 초기 카탈로그·기준 데이터를 멱등 적재하는 rake 태스크 모음입니다. `db/seeds.rb` 가 이들을 `Rake::Task["..."].invoke` 로 호출하므로, 실제 시드 로직은 대부분 여기에 있습니다. 모든 태스크는 `find_or_initialize_by`/`find_or_create_by!` 기반이라 재실행해도 안전합니다. (`config/application.rb` 의 `autoload_lib(ignore: %w[assets tasks])` 로 오토로드 대상에서는 제외됨.)

## 파일

- `schools.rake` — 세 태스크. **`schools:seed`**(CSV가 없는 개발/테스트용 축소 17교, production no-op). **`schools:fetch`**(키 필요; NEIS 전 페이지 수집→전국 검증→정렬→임시파일 fsync/원자 rename으로 `db/seeds/schools.csv` 교체, 실패 시 기존 파일 보존). **`schools:seed_full`**(CSV 헤더·구조·17개 교육청·최소 5,000교 검증 후 1,000행 배치 upsert; 현 스냅샷 학교는 neis/active, 사라진 기존 NEIS 학교와 구 합성 17교는 삭제 대신 inactive, manual 학교는 보존). 오프라인·멱등이며 CSV 경로는 `ENV["SCHOOLS_CSV"]`, 소형 테스트 fixture는 `SCHOOLS_ALLOW_PARTIAL=1`로 주입한다.
- `books.rake` — 일곱 태스크. **`books:seed`**는 호환 태스크명으로 ISBN이 검증된 TSV가 있으면 `books:seed_full`에 위임하고, 없으면 제목-only 카탈로그를 만들지 않고 no-op 한다. **`books:seed_full`**은 `db/seeds/elementary_books.tsv`를 오프라인·멱등 적재하며 ISBN 공란·체크디지트 오류 행을 각각 집계해 제외하고, 정규화 ISBN-13으로 동일 `searched` 행까지 제자리 승격한다. TSV 값이 있는 메타만 비파괴 갱신하고 summary는 보존한다(`ENV["BOOKS_TSV"]`로 테스트 파일 주입). **`books:enrich`**는 기존 ISBN 정확 일치 결과로 표지·출판사만 수동 네트워크 보강한다. **`books:deduplicate_isbn`**은 제약 도입 전 레거시의 정규화 ISBN 중복과 고신뢰 공란-ISBN 그림자를 기본 dry-run으로 보고하고, `APPLY=1`일 때만 참조 이관·메타 병합·중복 삭제한다(`INCLUDE_SHADOWS=0`으로 ISBN 중복만 제한, system quiz 충돌은 skip). **Gemini 줄거리 YAML 시드 3종(`db/seeds/book_summaries.yml` — Gemini 생성분만, `summary_checked_at` present 로 구분, 무키 배포도 시드로 접지 요약 확보)**: **`books:export_summaries`**(현재 DB의 Gemini 생성 요약을 YAML 로 export — 무키·무네트워크, 초기 파일 부트스트랩·crash-safe 재수출 담당) · **`books:seed_summaries`**(YAML→DB, **summary 가 blank 인 매칭 도서만** summary+summary_checked_at 주입, 무키·무네트워크·멱등, ISBN 미매칭 skip, YAML 없음/빈 경우 0건 크래시 0; `db:seed` 배선 — `ENV["BOOK_SUMMARIES_YML"]`로 테스트 파일 주입) · **`books:generate_summaries[limit]`**(카탈로그[classic/recommended] 중 ①summary blank ②checked_at nil ③YAML 미포함 ISBN 인 책을 classic 우선·id asc 로 limit+일일 예산 하 **동기 처리[`BookSummaryJob.perform_now` — dev async 큐라 perform_later 금지]**, known→YAML+DB·모름→checked_at만, 각 known 직후 YAML rewrite[crash-safe]; 무키면 skip. **네트워크는 이 태스크에서만**).
- `monsters.rake` — `monsters:seed`(전체 24라인 72폼)·`monsters:seed_phase2`(Phase 1 위에 Phase 2 12라인 36폼 추가)·**`monsters:backfill_unlocks`**(`User.student.find_each`로 기존 학생 전원의 몬스터 해금을 `MonsterUnlock#evaluate!`로 재평가 — unlock_condition 롤아웃 후 소급 지급용 배치, `(user_id, dex_no)` 유니크+미보유 가드로 재실행해도 멱등. 과거 게임 플레이는 `game_plays` 원장에 없어 게임 조건 라인은 신규 플레이부터 누적)·`monsters:install_assets`(YAML 매핑 검증 후 애니메이션 WebP 72개를 `app/assets/images/monsters`에 멱등 설치). 종 데이터 적재는 `MonsterSeeder`가 담당하며 소스는 `db/seeds/monsters.yml`(라인 단위 `unlock_condition`은 stage 1 폼에만 포함).
- `quizzes.rake` — `quizzes:seed`. 시드된 도서 1권(기본 "마당을 나온 암탉")에 대해 게시(published) 전역 퀴즈 1개를 만들어 quiz(mcq) 게임을 즉시 플레이 가능하게 함. 문항은 `Ai::QuizDraftService` 로 5개 생성. `title` 기준 멱등. **Phase 1 콘텐츠축 메타(#9-seed)**: 퀴즈에 origin=teacher·content_axis=mcq·band(전역이라 g56 폴백)·content_version=1, 문항에 question_type=mcq_single·source=manual 을 명시해 신규 컬럼과 함께 재현되게 함(`test/tasks/quizzes_seed_test.rb`).
- `badges.rake` — `badges:seed`(뱃지 13종) + `shop_items:seed`(먹이·진화의 돌·장식 상점 아이템). 각각 `key`/`name` 기준 멱등.
- `games.rake` — 세 태스크. **`games:warm`**(Phase 3 §3.5, A5). 카탈로그(추천/고전) 도서를 대상으로 `Games::ContentProvider.warm!` 로 **band×content_axis 워밍 잡을 사전 큐잉**해 학생 첫 플레이의 콜드-첫-오프라인 노출(특히 hint_reveal)을 줄인다(게임 재구성 Phase 1: matching 생성 경로 제거로 mcq·hint_reveal 만 워밍). 예산·rate limit·스코프 플래그를 준수하고 무키면 아무것도 적재하지 않으며(오프라인만), dedup(이미 워밍 중/AI 게시됨)은 `GenerateGameContentJob` 이 자체 가드한다. **`games:backfill_book_summaries`**(게임 재구성 Phase 4 §1d 벌크 백필). 줄거리도 없고 Gemini 확인도 안 한(`summary` blank·`summary_checked_at` nil) 카탈로그(고전/추천) 도서에 `BookSummaryJob` 을 `RateLimiter` 일일 예산(`WARMING_DAILY_BUDGET`) 하 페이싱해 큐잉한다(고전 우선). **무키면 0건**(`Ai::GeminiClient.available?` 가드로 무의미한 큐잉 차단). 잡이 멱등이라 재실행 안전. **`games:content_health`**(게임 재구성 Phase 5 §7·§8 사후 측정). **읽기 전용 콘텐츠 건강 스냅샷**(운영 모니터링용, 쓰기 0·신규 테이블 0) — 기존 substrate만 집계 출력: ①축별(mcq/hint_reveal) 서빙 소스 분포(ready·미신고 system 퀴즈의 `quiz_questions.source` offline/ai/contributed) ②`games:moderation_reject:{axis}` 캐시 카운터 ③quiz_reports 총계 + 신고율 프록시(reports/game_plays) ④summary 커버리지(있음/Gemini 모름[확인·blank]/미확인) ⑤`QuizContribution` status별(pending/approved/rejected) ⑥카탈로그(recommended+classic) 게임 가용성 커버리지(AI-적격[classic·summary] 또는 어느 밴드에든 ai/contributed 실질 콘텐츠 있는 책 비율, 전 밴드 합산). 무키·빈 데이터에서도 크래시 0(0/빈 값 정상 출력). 세 태스크 모두 시드 아닌 운영 태스크(스케줄/수동 실행).
- `missions.rake` — **시드 아닌 데이터 전환 태스크**(menu_refactor 심화 §2.B, PR1). **`missions:backfill_legacy`**(멱등: 레거시 참여 `reports.mission_id` 별 `[mission, user]` 최초 시각으로 완료 `MissionParticipation` 을 `find_or_initialize` + `||=` 백필해 `ReadingStats#missions` 를 completed_at 기준으로 전환[PR2]해도 몬스터 조건이 퇴행하지 않게 보존; 실제 완료행은 skip, 레거시는 `reward_points_awarded=0`; 목표 없는 참여 미션은 `status=archived`; `created_by_id` 는 담임으로 백필) + **`missions:verify_backfill`**(학생별 old[reports distinct mission_id] vs new[완료 participation] 대조, mismatch 출력·있으면 abort — **mismatch=0 이 reader 전환 PR2 배포 게이트**). 개발 DB에 레거시 미션이 없으면 vacuously 통과(created=0).

## 패턴·규칙

- **`db/seeds.rb` 와의 관계**: 학교는 `schools.csv` 존재 시 `schools:seed_full`(없으면 `schools:seed`)을 선택하고, 도서는 ISBN이 검증된 `books:seed_full`만 호출한다(파일 미존재 시 no-op, 축소 폴백 없음). 전체 순서는 학교 → superadmin/system/sample users → monsters/badges → 도서 → 공식 추천도서 → quizzes → app_settings이며, `quizzes:seed`는 superadmin·도서 이후여야 한다.
- 새 시드 태스크는 반드시 멱등하게 작성하고, 필요 시 `db/seeds.rb` 의 invoke 순서에 등록할 것.
