[책갈피] setup-and-run.bat 가 차단될 때 읽어 주세요
=====================================================

■ 증상
  더블클릭하면 아래와 같은 창이 뜨고 실행되지 않습니다.
    "스마트 앱 컨트롤이 안전하지 않을 수 있는 파일(앱)을 차단했습니다"
    "Windows의 PC 보호"(SmartScreen)

■ 원인
  인터넷에서 받은 압축파일(zip)을 풀면 그 안의 모든 파일에 '차단' 표시
  (Mark of the Web)가 붙습니다. Windows 11 의 스마트 앱 컨트롤은 이 표시가
  붙은 스크립트(.bat / .ps1)를 "서명·평판이 없다"는 이유로 내용과 무관하게
  실행 전에 막습니다. 파일이 손상되었거나 위험해서가 아닙니다.

  아래 1 → 2 → 3 순서로 시도해 보세요. 대개 1번에서 해결됩니다.


─────────────────────────────────────────────────────
해결 1. '차단' 표시 지우기   (가장 간단, 권장)
─────────────────────────────────────────────────────
  (A) 아직 압축을 풀기 전이라면 — zip 파일 하나만 해제하면 끝납니다.
      1) 받은 zip 파일에 마우스 오른쪽 클릭 → [속성]
      2) [일반] 탭 맨 아래 "보안: ... 차단 해제(Unblock)" 체크
      3) [확인] → 그 다음에 압축을 풉니다.

  (B) 이미 압축을 풀었다면 — 폴더째 한 줄로 해제합니다.
      1) 소스 폴더(compose.yaml 이 보이는 폴더)를 파일 탐색기로 엽니다.
      2) 탐색기 위쪽 주소창에 powershell 이라고 입력하고 Enter.
      3) 열린 창에 아래 한 줄을 붙여넣고 Enter:

            Get-ChildItem -Recurse | Unblock-File

      4) 다시 windows\setup-and-run.bat 를 더블클릭합니다.


─────────────────────────────────────────────────────
해결 2. Docker Desktop 으로 실행   (가장 확실)
─────────────────────────────────────────────────────
  Docker Desktop 은 정식 서명된 설치 프로그램이라 스마트 앱 컨트롤과
  충돌하지 않습니다. 설치 후에는 명령 한 줄이면 됩니다.

      1) https://www.docker.com/products/docker-desktop/ 에서 설치 → 재부팅
      2) Docker Desktop 실행 (고래 아이콘이 초록색이 될 때까지 대기)
      3) 소스 폴더 탐색기 주소창에 cmd 입력 → Enter
      4) docker compose up

  브라우저에서 http://localhost:3000 을 열고, 로그인 화면의
  "🚀 바로 체험해 보기" 버튼을 누르면 계정 입력 없이 바로 들어갑니다.


─────────────────────────────────────────────────────
해결 3. 스크립트 파일 없이 명령으로 직접 실행
─────────────────────────────────────────────────────
  Docker Desktop 을 설치할 수 없는 PC 용입니다. .bat / .ps1 파일을 전혀
  실행하지 않으므로 스마트 앱 컨트롤의 차단 대상이 되지 않습니다.
  (WSL 안의 리눅스 스크립트는 스마트 앱 컨트롤 적용 대상이 아닙니다.)

  시작 단추에서 "PowerShell" → [관리자 권한으로 실행] 후, 아래를 순서대로.

    # 1) WSL2 + Ubuntu 설치 (최초 1회) — 끝나면 재부팅한 뒤 2)번부터 이어서
    wsl --install -d Ubuntu

    #    Ubuntu 창이 열리면 안내에 따라 사용자 이름·암호를 한 번 만들고 창을 닫습니다.

    # 2) 소스 폴더(compose.yaml 이 들어 있는 폴더)로 이동 — 경로는 실제 위치로 바꾸세요
    cd C:\chaekgalpi
    $src = ((wsl -d Ubuntu -u root -e wslpath -a "$PWD") | Select-Object -First 1).Trim()

    # 3) Ubuntu 안에 Docker 설치 (수 분)
    wsl -d Ubuntu -u root -- bash -c "tr -d '\r' < '$src/windows/setup-wsl.sh' > /root/s.sh && bash /root/s.sh provision"
    wsl --shutdown

    # 4) 앱 빌드·실행 (최초 1회는 수 분~십수 분)
    wsl -d Ubuntu -u root -- bash -c "SRC_DIR='$src' bash /root/s.sh run"

  "준비 완료" 가 뜨면 브라우저에서 http://localhost:3000 을 엽니다.
    · 정지    : wsl -d Ubuntu -u root -- bash -c "cd /root/chaekgalpi && docker compose down"
    · 로그    : wsl -d Ubuntu -u root -- bash -c "cd /root/chaekgalpi && docker compose logs -f app"


─────────────────────────────────────────────────────
(참고) 스마트 앱 컨트롤을 끄는 방법 — 권장하지 않습니다
─────────────────────────────────────────────────────
  설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤
       → 스마트 앱 컨트롤 설정 → [끄기]

  ※ 한 번 끄면 Windows를 다시 설치하기 전에는 되돌릴 수 없습니다.
     심사·업무용 PC에서는 위 해결 1~3 을 사용해 주세요.
