# 「책갈피」 반려 몬스터 도감 — 나의 독서 친구를 소개해요! 📖🐾

> 안녕! 「책갈피」에는 여러분과 함께 책을 읽고 무럭무럭 자라는 **반려 몬스터**가 살고 있어요.
> 이 문서는 우리 앱에 나오는 몬스터가 무슨 친구들인지, 어떻게 만나고, 어떻게 진화하는지 소개하는 **도감 안내서**예요.

---

## 1. 반려 몬스터란? (총론)

### 🐣 나만의 독서 친구
반려 몬스터는 여러분의 **분신(아바타)** 이에요. 프로필에 얼굴 사진 대신 내 몬스터가 나타나서, 내가 책을 읽고 독후감을 쓸 때마다 곁에서 함께 자라요. 강아지·고양이·햄스터처럼 **우리 주변에서 흔히 보는 친숙한 동물**이나 연필·로봇 같은 **사물**, 그리고 유니콘·용 같은 **상상 속 친구**까지 아주 다양하답니다.

### 🎮 몬스터가 앱에서 하는 일
1. **나의 얼굴** — 트레이너(여러분!)의 프로필과 게시판에서 나를 대표해요.
2. **함께 자라는 짝꿍** — 내가 책을 많이 읽고 독후감을 잘 쓸수록 몬스터가 진화해요.
3. **도감 수집의 재미** — 총 **24종류(라인)** 의 몬스터를 하나씩 발견해 나만의 도감을 채워요.
4. **좋은 독서 습관 길잡이** — 몬스터마다 진화 조건이 달라서, 자연스럽게 여러 가지 독서 습관을 길러 줘요.
5. **뱃지·보상과 연결** — 진화하거나 도감을 채우면 특별한 뱃지를 받아요(§5).

### 🤝 몬스터를 만나는 방법
- **가장 처음:** 가입하면 **스타터 3종** 중에서 마음에 드는 **한 마리**를 골라요.
  - 💜 **갈피멍**(강아지) · 💙 **아롱냥**(고양이) · 💚 **새싹도치**(고슴도치)
- **그 다음부터:** 트레이너 레벨업, 챌린지 성공, 뱃지 획득 같은 **마일스톤을 달성할 때마다** 새 몬스터를 발견해요.
- **초반 해금 후보:** 💗 **콩닥이**(햄스터) · 🧡 **방향곰**(곰) · 🌈 **꼬마유니콘**(유니콘)도 일찍 만날 수 있어요.
- ⚠️ **뽑기(가챠)는 없어요!** 오직 책을 읽고 활동하는 것만으로 모든 몬스터를 만날 수 있답니다.

### ✨ 진화의 비밀
몬스터는 **3단계**로 자라요: **기본형(아기) → 성장형 → 완전형(최종)**.
진화하려면 **두 가지 종류의 조건을 모두(AND)** 채워야 해요.
1. **트레이너 포인트** — 활동으로 모으는 점수예요.
2. **독서 행동 조건** — 독후감 쓰기, 여러 장르 읽기, A등급 받기 같은 실제 독서 활동이에요.

> 💡 완전형(3단계)일수록 조건이 어려워요. 특히 **A등급 첨삭, 고전 읽기, 고쳐쓰기, 도감 수집** 같은 "정성 들인 독서"를 해야 최종 진화에 다다를 수 있어요. 그냥 빨리 읽는 것보다 **깊고 꾸준하게** 읽는 친구가 멋진 몬스터를 갖게 되는 거예요!

## 2. 6가지 속성 한눈에 보기

모든 몬스터는 6가지 **속성** 중 하나에 속하고, 속성마다 길러 주는 독서 습관과 색깔이 달라요.

| 속성         | 색깔      | 성격          | 키워드가 되는 독서 습관                        | 대표 친구들                 |
| ------------ | --------- | ------------- | ---------------------------------------------- | --------------------------- |
| 💜 **이야기** | 보라      | 이야기·글쓰기 | 꾸준히 독후감 쓰고 표현·토론하기               | 강아지·앵무새·연필·여우     |
| 💙 **지식**   | 파랑      | 지혜·탐구     | 다양한 장르·고전·퀴즈로 탐구하기               | 고양이·부엉이·로봇·거북이   |
| 💗 **감성**   | 분홍      | 마음·공감     | 감상 표현하고 친구 응원하기                    | 햄스터·고래·토끼·사슴       |
| 🧡 **모험**   | 주황      | 용기·도전     | 연속 독서·미션·챌린지 도전하기                 | 곰·병아리·펭귄·공룡         |
| 💚 **자연**   | 초록      | 성실·성장     | 성실하게 활동하고 고쳐쓰기                     | 고슴도치·개구리·다람쥐·버섯 |
| 🌈 **상상**   | 무지개/금 | 창의·종합     | 도감 수집·창의 활동으로 종합 성취(가장 어려움) | 유니콘·나비·도깨비·용       |

### 🏅 등급(레어도)
- **일반(common)** — 자주 만나는 친근한 친구
- **레어(rare)** — 조금 특별한 친구
- **에픽(epic)** — 아주 귀하고 강력한 친구 (거북이·용)

## 3. 진화 조건 낱말 사전

진화표에 나오는 말들을 쉽게 풀면 이래요. 여러 조건이 함께 적혀 있으면 **전부** 채워야 해요.

| 조건                   | 무슨 뜻일까?                                |
| ---------------------- | ------------------------------------------- |
| **포인트**             | 활동으로 모은 트레이너 포인트(점수)         |
| **독후감 N편**         | 선생님께 **승인받은** 독후감 수             |
| **A등급 / B등급 이상** | 첨삭에서 받은 등급 (A는 아주 잘 쓴 독후감!) |
| **장르 N종류**         | 서로 다른 종류의 책을 읽은 가짓수           |
| **고전 N권**           | 완독한 고전 책 수                           |
| **고쳐쓰기 N회**       | 첨삭 받고 **더 좋아지게** 다시 쓴 횟수      |
| **연속 독서 N일**      | 하루도 안 빠지고 이어서 읽은 날 수(스트릭)  |
| **미션 / 챌린지**      | 참여한 미션·완료한 챌린지 수                |
| **퀴즈·게임 N회**      | 독서 퀴즈나 게임을 플레이한 횟수            |
| **토론 글 N개**        | 토론 게시판에 올린 글 수                    |
| **받은 응원 N개**      | 내 글에 친구들이 눌러 준 응원 수            |
| **도감 N종류**         | 지금까지 도감에 모은 몬스터 라인 수         |
