심사위원 체험 매뉴얼
본 프로그램은 두 가지 방법으로 체험하실 수 있습니다. 편하신 방법을 선택하세요.
  • 방법 1 — 인터넷 접속: 주소 하나만 클릭하면 바로 체험 (가장 간단)
  • 방법 2 — 내 컴퓨터에서 실행: USB의 소스코드를 직접 실행 (Docker 이용)
두 방법 모두 로그인 계정과 사용법은 동일합니다(뒷장 참조).

크롬·엣지 등 웹브라우저에서 아래 주소로 접속하시면 별도 설치 없이 바로 체험하실 수 있습니다.

방법 2 · 내 컴퓨터(USB)에서 직접 실행하기

인터넷 없이 소스코드를 직접 실행해 보실 수 있습니다. Docker Desktop(USB에 포함)만 설치하면 됩니다. Ruby·리눅스 등 사전 지식은 필요 없습니다.

  1. Docker Desktop 설치 — USB의 DockerDesktopInstaller.exe 를 실행해 설치합니다. 설치 중 "WSL 2" 옵션은 켜 둔 채 진행하고, 안내에 따라 재부팅합니다. 재부팅 후 Docker Desktop을 실행해 좌측 하단 고래 아이콘이 초록색이 될 때까지 기다립니다.
  2. 소스코드 폴더 복사 — USB의 chaekgalpi(소스) 폴더를 컴퓨터(예: C:\chaekgalpi)로 복사합니다.
  3. 그 폴더에서 명령창 열기 — 복사한 폴더를 파일 탐색기로 연 뒤, 주소창에 cmd 를 입력하고 Enter 를 누릅니다.
  4. 프로그램 준비(이미지 불러오기) — 아래 명령을 입력합니다(USB에 담긴 미리 만든 실행 이미지를 불러옵니다. 인터넷 불필요). 
    docker load -i chaekgalpi-app.tar.gz
  5. 실행 — 이어서 아래 한 줄을 입력합니다. 
    docker compose up --no-build
    처음 실행은 데이터 준비로 수 분 걸립니다. ✅ 준비 완료! 메시지가 나오면 다음 단계로.
  6. 브라우저로 접속 — 크롬·엣지에서 http://localhost:3000 을 엽니다.
인터넷이 되는 환경이라면, 이미지 불러오기(4단계) 없이 소스에서 직접 빌드할 수도 있습니다: docker compose up (구성요소를 내려받아 빌드 → 다소 오래 걸림). 결과는 동일합니다.
종료·초기화 — 명령창에서 Ctrl+C 로 종료. docker compose down 정리(데이터 보존) / docker compose down -v 완전 초기화.
