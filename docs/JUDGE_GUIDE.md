## 🧭 5분 둘러보기 코스 (추천 동선)

### 1. 학생 체험 — 핵심 가치 ①②③ (약 3분)
`김예준` 학생으로 로그인 후:
1. **홈** — 반려 몬스터, 진행 중 미션, 나의 성장이 한눈에.
2. **독서활동** — 책을 고르고 **독후감 쓰기**. 제출하면 **AI 5축 첨삭**(내용·감상·삶·구성·맞춤법)이
   **방사형(radar) 차트**로 표시됩니다. "점수 매기기"가 아니라 **발전적 첨삭**이 설계 철학입니다.
   - 💡 이미 채점된 기존 독후감을 열어 보면 5축 차트·교사 코멘트·고쳐쓰기 흐름을 바로 볼 수 있습니다.
3. **독서 게임** — 책을 고르면 즉석 퀴즈가 생성됩니다(추론·독해 등).
4. **도감(반려 몬스터)** — 6속성 24진화라인 **72폼**. 독서 성취마다 새 몬스터를 발견·**진화**시킵니다.
5. **나의 성장 / 랭킹** — 5축 자기비교, 닉네임 기반 랭킹(개인정보 보호).

> ℹ️ **AI 첨삭 안내**: 데모 서버에 Gemini 키가 없으면, 새로 쓴 독후감은 **규칙기반 첨삭**으로 즉시
> 응답합니다(의도된 무중단 폴백 — 키 없이도 5축·차트가 동작). 키가 설정돼 있으면 실제 Gemini 첨삭이 나옵니다.

### 2. 담임교사 체험 — 학교 현장 운영 (약 2분)
`teacher.wondong61@chaekgalpi.demo` 로 로그인 후:
1. **검토 큐** — 학생 독후감을 열어 **5축 점수 조정·승인·AI 진위 확인**.
2. **학생 관리** — 비밀번호 재설정·포인트 부여.
3. **문서 출력** — **표창장·가정통신문·독서 포트폴리오·학급 성장 리포트** 인쇄 미리보기.
4. **미션·퀴즈** — 학급 미션 발행, 학생 출제 문제 검토.

### 3. 그 밖의 역할 (선택)
- **교무관리자**: 전교 통계 대시보드 + NEIS 생기부 자동 요약.
- **사서**: 도서관 대시보드, 인기대출(정보나루)·이달의 책·행사.
- **총괄관리자**: `/admin` — 전국 학교·사용자·도서·콘텐츠 관리와 전역 분석.

## ✨ 이 앱의 핵심

| 핵심 가치 | 내용 |
|-----------|------|
| **AI 5축 발전적 첨삭** | 내용·감상·삶·구성·맞춤법 5축을 방사형 차트로. 사진 손글씨 OCR·음성 등 다양한 입력. |
| **반려 몬스터 도감·진화** | 24라인 × 3단계 = **72폼**. 가챠 없이 독서 성취로만 획득·진화. |
| **학교 현장 5역할 운영** | 검토·통계·도서관·문서출력·관리자를 하나의 앱으로. |
| **무중단 설계** | 외부 API(Gemini·네이버·정보나루) 키가 없어도 폴백으로 완전 동작. |

- **규모**: 구현 Phase 0~8 완료 · 테스트 1,441개 통과 · RuboCop 무경고 · Brakeman 0
- **기술**: Ruby on Rails 8.1 · Hotwire · SQLite 다중 DB · Pundit(역할·학교 경계 격리)
