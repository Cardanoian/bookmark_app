# 📚 사서 사용 매뉴얼 — 책갈피

> 이 매뉴얼은 **사서(librarian)** 가 「책갈피」로 학교 도서관을 운영하는 방법을 안내합니다.
> 사서는 **인기 대출 도서 집계**, **이달의 책·행사 등록**, **도서관 현황 확인**을 담당합니다.

---

## 1. 사서가 하는 일 (한눈에)

| 영역 | 할 수 있는 것 |
|------|--------------|
| 📊 도서관 대시보드 | 전교 독후감 수·참여 학생 수·인기 도서·행사 현황 보기 |
| 📈 인기 대출 관리 | 정보나루 API 동기화 / 교육청 CSV 업로드 / 수동 입력 |
| 📅 이달의 책·행사 | 도서관 행사 등록·수정·삭제 |

> 🔒 사서는 **자기 소속 학교**의 도서관 데이터를 관리합니다. (인기 대출은 전국 데이터도 참고로 함께 봅니다)

---

## 2. 로그인하기

1. 첫 화면에서 **👩‍🏫 선생님 로그인**(교직원 로그인)을 선택합니다.
2. **이메일 + 비밀번호**로 로그인합니다.

> ℹ️ 사서 계정은 **직접 가입할 수 없습니다.** 총괄관리자가 계정을 만들거나 역할을 부여해 줍니다.

---

## 3. ⚠️ 꼭 알아둘 점 — 실제 업무 화면 주소

로그인하면 나오는 첫 화면(`/`)은 **간단한 안내 화면**이며, 여기에는 아직 기능 버튼이 연결되어 있지 않습니다.
**실제 사서 업무 화면은 아래 주소로 직접 들어가야 합니다.**

| 화면 | 주소 |
|------|------|
| 🏠 **사서 대시보드** (여기서 시작하세요) | `/librarian/dashboard` |
| 📈 인기 대출 관리 | `/librarian/loans` |
| 📅 이달의 책·행사 | `/librarian/events` |

> 💡 **팁:** 로그인 후 브라우저 주소창에 `/librarian/dashboard`를 입력해 **즐겨찾기(북마크)** 해 두세요.
> 대시보드에 들어가면 그 안에서 **"인기 대출" · "이달의 책·행사"** 버튼으로 서로 이동할 수 있습니다.

---

## 4. 📊 사서 대시보드 (`/librarian/dashboard`)

도서관 운영을 시작하는 중심 화면입니다.

- **상단 통계 카드 3개**
  - 전교 독후감 수
  - 참여 학생 수 (독후감을 쓴 학생 수)
  - 등록 행사 수
- **인기 도서(대출) Top 10** — 우리 학교 + 전국(정보나루) 대출 순위. 전국 데이터에는 "전국" 배지가 붙습니다.
- **이달의 책·행사** — 등록된 행사 목록. "새 행사" 링크로 바로 등록할 수 있습니다.

---

## 5. 📈 인기 대출 관리 (`/librarian/loans`)

인기 대출 데이터를 넣는 방법은 **3가지**입니다.

### 방법 ① 정보나루(data4library) 동기화 — 자동

- **"정보나루 동기화"** 버튼을 누르면, 정보나루 공공 API에서 **전국 인기대출 순위(직전 달)** 를 자동으로 가져옵니다.
- ⚠️ **API 키가 없으면** "정보나루 API 키가 없어요 — CSV 업로드를 사용하세요"라고 안내가 뜹니다. 이때는 방법 ②를 쓰세요.
- 네트워크 문제로 실패해도 앱이 멈추지 않고, CSV 업로드로 대체하라는 안내가 나옵니다.

### 방법 ② 교육청 DLS CSV 업로드 — 우리 학교 데이터

- 교육청 도서관 시스템(DLS)에서 받은 **CSV 파일**을 업로드합니다.
- 파일을 고른 뒤 **"CSV 업로드"** 를 누릅니다.
- CSV의 열 제목은 한글·영어 모두 인식합니다: `도서명/title`, `isbn`, `대출건수/count`, `기간/period`
- 이 데이터는 **우리 학교** 기준으로 저장됩니다.

### 방법 ③ 수동 입력

- 화면 아래 폼에 **도서명 · 대출건수 · 기간**을 직접 넣고 **"추가"** 를 누릅니다.

> 💡 **중복 걱정 없음:** 같은 `학교 + 도서명 + 기간` 조합은 새로 추가되지 않고 **덮어쓰기(갱신)** 됩니다. 그래서 CSV를 다시 올려도 안전해요.

---

## 6. 📅 이달의 책·행사 관리 (`/librarian/events`)

도서관 행사를 등록·관리합니다.

### 행사 등록

1. **"행사 등록"** 을 누릅니다.
2. **제목**(필수), **설명**, **행사일**, **추천 도서**(선택 — 기존 도서 중에서 지정)를 입력합니다.
3. 저장하면 우리 학교 행사로 등록됩니다.

### 행사 수정·삭제

- 행사 상세 화면에서 **수정** 또는 **삭제**(확인창)를 할 수 있습니다.

> 🔒 다른 학교의 행사에는 접근할 수 없습니다.

---

## 7. 🔒 권한 경계 (할 수 있는 것 / 없는 것)

| 할 수 있는 것 ✅ | 할 수 없는 것 ❌ |
|------------------|------------------|
| 도서관 대시보드·통계 보기 | 도서 카탈로그 자체 등록/수정 (→ 총괄관리자) |
| 인기 대출 집계(API·CSV·수동) | 독후감 검토·승인·수정 |
| 이달의 책·행사 등록·관리 | 학생 계정·포인트 관리 |
| 우리 학교 데이터 관리 | 다른 학교 데이터 접근 |

> ℹ️ **도서 등록에 관하여:** 새 책을 카탈로그에 등록·수정·삭제하는 것은 **총괄관리자**의 권한입니다.
> 사서는 이미 등록된 도서를 **행사의 추천 도서로 연결**하는 방식으로 활용합니다. 새 도서 등록이 필요하면 총괄관리자에게 요청하세요.

---

## 🌟 정리 — 사서의 사용 흐름

1. **로그인**(이메일) → 주소창에 `/librarian/dashboard` 입력해 대시보드 열기
2. **대시보드**에서 도서관 현황·인기 도서·행사 확인
3. **인기 대출 관리**에서 정보나루 동기화 또는 CSV 업로드로 순위 갱신
4. **이달의 책·행사**에서 도서관 행사 등록·관리

핵심은 **`/librarian/dashboard`를 북마크해 두는 것**과, 인기 대출 데이터를 **정기적으로(월 1회 등) 갱신**하는 것입니다. 📚
