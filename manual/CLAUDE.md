## 작성 원칙

- 대상은 **초등 전학년 학생과 학교 현장 교직원** → 코드 용어·파일 경로 대신 **화면·버튼·주소** 중심으로 쉽게 서술.
- 각 문서는 공통 틀을 따름: `역할 소개 → 로그인 → 첫 화면/메뉴 → 기능별 사용법 → 권한 경계 → 정리(사용 흐름)`.
- 코드 기반으로 확인된 **실사용상 주의점**(예: 사서·교무의 실제 업무 화면 URL 직접 접근, 독후감 폼의 책 제목 직접 입력, 승인이 몬스터 진화에 필요함 등)을 함께 안내.
