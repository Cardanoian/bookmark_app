# 🛠️ 총괄관리자 사용 매뉴얼 — 책갈피

> 이 매뉴얼은 **총괄관리자(superadmin)** 가 「책갈피」 전체 시스템을 운영하는 방법을 안내합니다.
> 총괄관리자는 **모든 학교·계정·콘텐츠**를 관리하는 최고 권한 역할이며, 전용 **관리자 콘솔(`/admin`)** 에서 작업합니다.

---

## 1. 총괄관리자가 하는 일 (한눈에)

| 영역 | 할 수 있는 것 |
|------|--------------|
| 📊 통합 통계 | 전체 학교 참여율·5축 평균·전국 랭킹 + CSV 내보내기 |
| 🏫 학교 관리 | 학교 등록·수정·삭제 |
| 👥 사용자 관리 | 계정 조회·수정, 역할 부여, 정지, 비번 초기화, 포인트 조정 |
| 📚 콘텐츠 관리 | 도서·퀴즈·뱃지·상점 아이템·몬스터 도감 CRUD |
| 🚩 모더레이션 | 신고된 게시글·토론 숨김/해제 |
| ⚙️ 시스템 설정 | 기능 플래그·루브릭 기본 가중치·시즌 배너 |

> 🔑 **최고 권한:** 총괄관리자는 모든 학교·모든 학급·모든 사용자에 접근할 수 있으며, 필요 시 교사 권한을 대행할 수도 있습니다.

---

## 2. 로그인과 자동 이동

1. 첫 화면에서 **👩‍🏫 선생님 로그인**(교직원 로그인)을 선택합니다.
2. **이메일 + 비밀번호**로 로그인합니다.
3. 로그인하면 **자동으로 관리자 콘솔 `/admin`** 으로 이동합니다.
   - (다른 역할과 달리, 총괄관리자는 일반 대시보드를 거치지 않고 바로 콘솔로 갑니다.)

> ℹ️ 총괄관리자 계정은 자가 가입이 없습니다. 최초 계정은 시스템 세팅(시드) 또는 기존 총괄관리자의 역할 부여로 생성됩니다.

---

## 3. 관리자 콘솔 둘러보기 (`/admin`)

콘솔은 **왼쪽 사이드바 + 오른쪽 작업 영역**으로 되어 있습니다. 사이드바 메뉴 10가지:

| 메뉴 | 주소 | 하는 일 |
|------|------|---------|
| 통합 통계 | `/admin` | 전체 현황 대시보드 (첫 화면) |
| 학교 관리 | `/admin/schools` | 학교 등록·수정·삭제 |
| 사용자 관리 | `/admin/users` | 계정·승인·역할·정지 관리 |
| 도서 | `/admin/books` | 도서 카탈로그 관리 |
| 퀴즈 | `/admin/quizzes` | 전역 퀴즈 관리 |
| 뱃지 | `/admin/badges` | 뱃지 관리 |
| 상점 아이템 | `/admin/shop_items` | 상점 아이템 관리 |
| 몬스터 도감 | `/admin/monster_species` | 몬스터 종·진화 규칙 관리 |
| 모더레이션 | `/admin/moderation` | 신고 콘텐츠 관리 |
| 시스템 설정 | `/admin/settings` | 시스템 설정 |

사이드바 아래에는 현재 로그인한 이름과 **로그아웃** 버튼이 있습니다.

---

## 4. 📊 통합 통계 (첫 화면, `/admin`)

로그인하면 처음 보이는 화면입니다.

- **상단 카드 3개**: 전체 학생 수 · 전체 독후감 수 · 승인(검토완료) 수
- **학교별 통계 표**: 학교마다 학생수·독후감수·참여율·5축 평균
- **전국 랭킹 원자료**: 포인트 상위 학생
- 상단 **"전교 CSV 내보내기"** 버튼으로 전체 원자료를 CSV로 내려받을 수 있습니다.

---

## 5. 👥 사용자 관리 (`/admin/users`) — 가장 중요

> ℹ️ **교사 가입 승인 절차는 없습니다.** 교사는 회원가입하면 곧바로 로그인·활동할 수 있어요. 총괄관리자가 따로 승인할 필요가 없습니다.

### 5-1. 사용자 관리 기능

| 기능 | 설명 |
|------|------|
| **검색·조회** | 이름·역할·학교로 필터링 |
| **역할 부여/변경** | 상세 화면의 "역할 변경"에서 학생/교사/교무관리자/사서/총괄관리자로 지정 |
| **계정 정지/해제** | 문제 계정을 정지하면 즉시 로그아웃됩니다 |
| **비밀번호 초기화** | 임시 비밀번호 재발급 |
| **포인트 조정** | 학생 포인트 목표값을 정하면 차액이 정상 지급/차감됩니다 (뱃지·진화·랭킹에 정합 반영) |

> 💡 **역할 부여로 계정 만들기:** 교무관리자·사서는 자가 가입이 없으므로, 해당 사용자의 **역할을 변경**해 교무관리자·사서로 지정하는 방식으로 만듭니다.

---

## 6. 🏫 학교 관리 (`/admin/schools`)

- 학교를 **등록·수정·삭제**합니다.
- 입력 항목: 학교명, NEIS 코드, 지역(시·도), 구, 교육청 코드 등.
- 학교 이름으로 검색할 수 있습니다.

---

## 7. 📚 콘텐츠 관리

| 메뉴 | 관리 내용 |
|------|-----------|
| **도서** (`/admin/books`) | 도서 카탈로그 CRUD — 제목·저자·ISBN·표지·요약·학년밴드·분류 |
| **퀴즈** (`/admin/quizzes`) | 전역 퀴즈 CRUD — 문항·보기(줄바꿈으로 구분)·정답 |
| **뱃지** (`/admin/badges`) | 뱃지 CRUD — 키·이름·아이콘·획득 조건 설명 |
| **상점 아이템** (`/admin/shop_items`) | 아이템 CRUD — 이름·분류·가격·소모품 여부·효과(JSON) |
| **몬스터 도감** (`/admin/monster_species`) | 몬스터 종·진화 규칙 CRUD — 속성·희귀도·진화 조건(JSON) |

> ℹ️ **도서 등록은 총괄관리자 권한입니다.** 사서가 새 도서 등록을 요청하면 여기서 처리합니다.

---

## 8. 🚩 모더레이션 (`/admin/moderation`)

- 학생들이 **신고한 게시판 글·토론글·토픽**을 관리합니다.
- 부적절한 콘텐츠는 **숨김** 처리할 수 있고(숨기면 학생 화면에서 사라집니다), 필요 시 **숨김 해제**도 가능합니다.

---

## 9. ⚙️ 시스템 설정 (`/admin/settings`)

- **시즌 배너**, **기능 플래그(JSON)**, **기본 루브릭 가중치(JSON)** 등을 설정합니다.
- ⚠️ **보안:** API 키류(Gemini·카카오·네이버·정보나루 등)는 이 화면에 **저장할 수 없습니다.** 보안을 위해 자동으로 거부·제거됩니다. API 키는 서버 환경변수/크리덴셜로만 관리하세요.

---

## 10. 🔑 계정 발급 규칙 정리 (관리자가 알아야 할 것)

| 역할 | 계정을 어떻게 만드나 |
|------|----------------------|
| 학생 | **담임교사**가 생성 (임시 비밀번호 자동 발급) |
| 교사 | **본인이 회원가입** (승인 절차 없이 가입 즉시 로그인) |
| 교무관리자·사서 | **총괄관리자가 역할 부여**로 지정 (자가 가입 없음) |
| 총괄관리자 | 시스템 세팅 또는 기존 총괄관리자가 역할 부여 |

> 💡 **비밀번호/프로필 변경:** 이 앱에는 사용자가 스스로 비밀번호를 바꾸는 화면이 없습니다. 초기화는 **교사(학생 대상)** 또는 **총괄관리자(전체 대상)** 가 대신 해 줍니다.

---

## 🌟 정리 — 총괄관리자의 사용 흐름

1. **로그인**(이메일) → 자동으로 `/admin` 콘솔 도착
2. **통합 통계**로 전체 현황 파악
3. **사용자 관리**에서 역할 부여 · 정지 · 포인트 조정
4. **학교 관리**로 학교 등록·정비
5. **콘텐츠 관리**(도서·퀴즈·뱃지·상점·몬스터)로 앱 내용 구성
6. **모더레이션·시스템 설정**으로 안전·운영 관리

가장 자주 하는 일은 **도서 등록**과 **콘텐츠 관리**입니다. API 키는 절대 시스템 설정에 넣지 말고 환경변수로 관리하세요. 🛠️
