# 🏫 교무관리자 사용 매뉴얼 — 책갈피

> 이 매뉴얼은 **교무관리자(school_admin, 교무)** 가 「책갈피」로 **학교 전체의 독서교육 현황**을 파악하는 방법을 안내합니다.
> 교무관리자는 **전교 통계 열람**과 **NEIS 생기부(독서활동상황) 자동 요약**을 담당하는 "학교 단위 감독·통계" 역할입니다.

---

## 1. 교무관리자가 하는 일 (한눈에)

| 영역 | 할 수 있는 것 |
|------|--------------|
| 📊 전교 통계 | 참여율·학년별·학급별 5축 평균·약점 진단 보기 |
| 📝 NEIS 생기부 요약 | 학생별 독서활동상황 생기부 문장 자동 생성 |

> 🔎 교무관리자는 **학교 전체를 볼 수 있지만**, 독후감을 직접 고치거나 학생을 관리하지는 않습니다. **"보고 요약하는"** 역할입니다.

---

## 2. 로그인하기

1. 첫 화면에서 **👩‍🏫 선생님 로그인**(교직원 로그인)을 선택합니다.
2. **이메일 + 비밀번호**로 로그인합니다.

> ℹ️ 교무관리자 계정은 **직접 가입할 수 없습니다.** 총괄관리자가 계정을 만들거나 역할을 부여해 줍니다.

---

## 3. ⚠️ 꼭 알아둘 점 — 실제 업무 화면 주소

로그인 직후 나오는 첫 화면(`/`)은 **간단한 안내 화면**이며, 아직 기능 버튼이 연결되어 있지 않습니다.
**실제 교무 업무 화면은 아래 주소로 직접 들어가야 합니다.**

| 화면 | 주소 |
|------|------|
| 📊 **전교 통계** (여기서 시작하세요) | `/school_admin/stats` |
| 📝 NEIS 생기부 요약 | `/school_admin/neis` |

> 💡 **팁:** 로그인 후 주소창에 `/school_admin/stats`를 입력해 **즐겨찾기(북마크)** 해 두세요.
> 전교 통계 화면에 들어가면 상단의 **"NEIS 생기부 요약"** 버튼으로 이동할 수 있습니다.

---

## 4. 📊 전교 통계 (`/school_admin/stats`)

우리 학교 전체 독서교육 현황을 보는 대표 화면입니다.

- **상단 통계 카드 4개**
  - 전교 참여율(%) — 독후감을 쓴 학생 / 전체 학생
  - 학생 수
  - 총 독후감 수
  - 학급 수
- **전교 5축 평균 레이더(방사형) 차트** — 학교 전체가 어떤 항목(내용·감상·삶·구성·맞춤법)에 강하고 약한지 그림으로 보여줍니다.
- **전교 약점 진단** — 가장 낮은 항목을 찾아 해당 **성취기준 코드 + 추천 활동**을 노란 박스로 안내합니다.
- **학년별 5축 평균 표** — 학년마다 독후감 수와 5축 평균을 보여줍니다.
- **학급별 현황 표** — 학급마다 참여율·독후감 수·5축 평균을 보여줍니다.

> 🔒 모든 통계는 **우리 학교** 범위로만 집계됩니다. 다른 학교 데이터는 보이지 않습니다.

---

## 5. 📝 NEIS 생기부 자동 요약 (`/school_admin/neis`)

학생 생활기록부의 **독서활동상황** 문장을 자동으로 만들어 주는 기능입니다.

### 사용 순서

1. 화면 위쪽 **학생 선택 드롭다운**에서 학생을 고릅니다.
2. **"요약 생성"** 을 누릅니다.
3. 그 학생의 독후감들을 모아 **3인칭 문어체 생기부 문장**이 자동으로 만들어집니다.
   - 예: "총 ○편의 독후감을 작성함", 강점 항목 문장, 고쳐쓰기가 있으면 "성장의 모습을 보임" 등
4. 만들어진 문장을 **"복사"** 버튼으로 복사해, **검토 후 NEIS에 붙여넣어** 사용합니다.

> 💡 이 기능은 **AI 키 없이도** 규칙 기반 템플릿으로 동작합니다. 결과는 반드시 **선생님이 검토·수정한 뒤** 사용하세요.

---

## 6. 🔍 교무관리자 vs 담임교사 — 무엇이 다른가요?

혼동하기 쉬운 두 역할의 차이입니다.

| 구분 | 교무관리자(교무) | 담임교사 |
|------|------------------|----------|
| 보는 범위 | **학교 전체** (모든 학급) | **자기 담임 학급만** |
| 독후감 검토·승인 | ❌ 못 함 | ✅ 함 |
| 학생 계정·포인트 관리 | ❌ 못 함 | ✅ 함 |
| 미션·퀴즈 만들기 | ❌ 못 함 | ✅ 함 |
| 통계 열람 | ✅ **전교** 통계 | 자기 학급 통계 |
| NEIS 생기부 요약 | ✅ (학교 전체 학생) | ❌ (교무 전용 기능) |

> 한마디로, **교무관리자 = 학교 전체를 보는 감독·통계·요약** 역할이고, **담임교사 = 자기 반을 직접 운영**하는 역할입니다.

---

## 7. 🔒 권한 경계 (할 수 있는 것 / 없는 것)

| 할 수 있는 것 ✅ | 할 수 없는 것 ❌ |
|------------------|------------------|
| 전교 통계·학년별·학급별 현황 열람 | 독후감 검토·승인·수정 |
| NEIS 생기부 요약 생성 | 학생 계정 추가·삭제·포인트 지급 |
| 학교 전체 데이터 열람 | 미션·퀴즈·루브릭 설정 |
| — | 다른 학교 데이터 접근 |

---

## 🌟 정리 — 교무관리자의 사용 흐름

1. **로그인**(이메일) → 주소창에 `/school_admin/stats` 입력해 전교 통계 열기
2. **전교 통계**에서 참여율·학년별·학급별 5축 평균·약점 확인
3. 상단 버튼으로 **NEIS 생기부 요약**으로 이동
4. 학생을 골라 **생기부 문장 자동 생성 → 복사 → 검토 후 NEIS에 활용**

핵심은 **`/school_admin/stats`를 북마크해 두는 것**과, 통계를 통해 학교 전체의 강·약점을 파악해 **선생님들과 공유**하는 것입니다. 🏫
