# 👩‍🏫 담임 선생님 사용 매뉴얼 — 책갈피

> 이 매뉴얼은 **담임교사**가 「책갈피」로 우리 반 학생들의 독서 활동을 관리하는 방법을 안내합니다.
> 선생님은 학생 계정 만들기, 독후감 검토·승인, 미션·퀴즈 만들기, 통계 보기, 문서 출력까지 **우리 반 운영의 모든 것**을 담당합니다.

---

## 1. 담임 선생님이 하는 일 (한눈에)

| 영역          | 할 수 있는 것                                          |
| ------------- | ------------------------------------------------------ |
| 📊 대시보드    | 우리 반 검토 대기·등급 비율·5축 평균·약점 진단 보기    |
| ✅ 독후감 검토 | AI 첨삭 확인 → 점수 조정 → 승인, 표절 의심 확인        |
| 👥 학생 관리   | 학생 추가·삭제, 비밀번호 초기화, 포인트 수동 지급      |
| 🎯 미션·퀴즈   | 독서 미션·퀴즈 만들기(퀴즈는 AI가 문항 초안 자동 생성) |
| ⚙️ 루브릭      | 우리 반 5축 채점 가중치 설정                           |
| 🖨️ 문서 출력   | 성적 CSV, 표창장·가정통신문·포트폴리오 인쇄            |

> 🔒 **경계:** 선생님은 **자기 담임 학급**만 관리할 수 있어요. 다른 반 학생·독후감에는 접근할 수 없습니다.

---

## 2. 로그인하기

1. 첫 화면에서 **👩‍🏫 선생님 로그인**(교직원 로그인)을 선택합니다.
2. **이메일 + 비밀번호**로 로그인합니다. (학생과 달리 이메일 로그인이에요)
3. 로그인하면 **선생님 콘솔** 첫 화면으로 이동합니다.

> ✅ **가입하면 바로 로그인됩니다.** 별도의 관리자 승인 절차는 없어요.

### 교사 계정 회원가입

- 로그인 화면의 **"교사 회원가입"** 링크에서 이메일·비밀번호·(담당 학급)을 입력해 가입합니다.
- 가입을 마치면 곧바로 로그인되어 선생님 콘솔로 이동합니다.

---

## 3. 첫 화면과 메뉴

로그인 후 첫 화면에는 **4개의 큰 카드**(학급 인사이트 / 학생관리 / 미션·퀴즈 / 문서 출력)가 있습니다.

화면 **왼쪽 사이드바**에 항상 아래 메뉴가 있습니다.

| 메뉴         | 하는 일                         |
| ------------ | ------------------------------- |
| 대시보드     | 우리 반 현황·통계               |
| 검토         | 독후감 검토·승인 (가장 자주 씀) |
| 학생관리     | 학생 추가·관리·포인트 지급      |
| 미션         | 독서 미션 만들기                |
| 퀴즈         | 독서 퀴즈 만들기                |
| 루브릭       | 5축 채점 가중치 설정            |
| CSV 내보내기 | 성적 데이터 내려받기            |

---

## 4. 📊 대시보드 (학급 인사이트)

**대시보드** 메뉴를 누르면 우리 반 현황이 한눈에 보입니다.

- **상단 4개 숫자**: 총 독후감 수 · 검토 대기 수 · A등급 비율 · 학생 평균 포인트
- **🚩 신고된 게임 콘텐츠**: 학생이 게임 중 신고한 내용을 확인용으로 보여줍니다.
- **5축 평균 방사형(레이더) 차트**: 우리 반이 어떤 항목에 강하고 약한지 그림으로 보여줍니다.
- **약점 인사이트**: 가장 낮은 항목을 찾아 **성취기준 코드 + 추천 활동**을 알려줍니다.
- **향상도 요약**: 학생들이 고쳐쓰기로 얼마나 좋아졌는지 보여줍니다.
- **검토 큐 요약**: 검토가 필요한 최근 독후감 5건을 바로 보여줍니다.

---

## 5. ✅ 독후감 검토·승인 (핵심 업무)

선생님의 가장 중요한 일입니다. **검토** 메뉴에서 진행합니다.

### 5-1. 검토 큐 (대기 목록)

- 학생이 독후감을 내면 AI가 자동으로 5축 첨삭을 하고, **검토 큐에 실시간으로 추가**됩니다. (새로고침 안 해도 올라와요)
- 각 줄에 학생 이름·책·평균 점수·유사도·등급이 보이고, **[검토]** 와 **[승인]** 버튼이 있습니다.
- 여러 개를 체크한 뒤 아래 **"선택 일괄 승인"** 으로 한 번에 승인할 수도 있습니다.

### 5-2. 독후감 상세 보기 (첨삭 확인 → 조정 → 코멘트)

**[검토]** 를 누르면 상세 화면이 열립니다.

1. **학생이 쓴 글 원문**을 읽습니다.
2. **AI 5축 첨삭**(내용·감상·삶·구성·맞춤법)을 막대그래프로 확인합니다.
3. 필요하면 각 항목의 **점수를 0~5로 직접 조정**하고, **교사 코멘트**를 적어 **저장**합니다.
   - (저장만으로는 아직 승인이 아니에요. 조정값·코멘트만 보관됩니다.)

### 5-3. 승인하기

- **[승인]** 을 누르면 독후감이 "검토 완료" 처리됩니다.
- 승인하면 학생 화면에 **선생님 확인**이 실시간으로 뜨고, 학생의 **뱃지·몬스터 진화 조건**이 다시 계산됩니다.

> 💡 **포인트는 승인할 때 새로 주는 게 아니에요.** 포인트는 AI 첨삭 시점에 이미 등급대로 지급됩니다. 승인은 "검토 완료" 표시 + 진화/뱃지 반영 역할을 합니다.
>
> 💡 진화 조건의 "독후감 개수"는 **선생님이 승인한** 독후감만 셉니다. 그래서 선생님의 승인이 학생의 게임 진행에 꼭 필요해요.

### 5-4. 진위·표절 확인

- 상세 화면에서 **"진위 확인"** 을 누르면 AI가 **표절 의심 정도**와 **우리 반 안에서의 최대 유사도**를 알려줍니다.
- (AI 키가 없으면 "판단 보류"로 나옵니다.)

---

## 6. 👥 학생 관리

**학생관리** 메뉴에서 우리 반 학생을 관리합니다.

### 학생 추가

- 위쪽 폼에 **이름**을 넣고(반이 여러 개면 반 선택) 추가합니다.
- 추가하면 **임시 비밀번호가 자동으로 생성**되어 화면에 표시됩니다. → 이 비밀번호를 학생에게 알려주세요.

### 그 밖의 관리

| 버튼                | 하는 일                                              |
| ------------------- | ---------------------------------------------------- |
| **+10P**            | 학생에게 포인트를 수동으로 지급 (예: 발표 잘했을 때) |
| **비밀번호 초기화** | 새 임시 비밀번호 발급 (학생이 잊었을 때)             |
| **삭제**            | 학생 계정 삭제 (확인창이 떠요)                       |

> 🔒 다른 반 학생은 추가·관리할 수 없습니다. (내 학급만 가능)

---

## 7. 🎯 미션 만들기

**미션** 메뉴에서 독서 미션을 만듭니다.

1. **"새 미션"** 을 누릅니다.
2. **제목**, (반 선택), **시작일·종료일**을 정합니다.
3. 저장하면 학생들이 미션 화면에서 **참여**할 수 있습니다.

학생이 참여한 뒤 쓰는 독후감이 미션에 집계되어, **진화·뱃지 조건**을 채우는 데 도움이 됩니다.

> 🔒 미션 "참여"는 학생만 할 수 있고, 선생님은 미션을 **만들고 관리**합니다.

---

## 8. 📝 퀴즈 만들기 (AI 자동 초안)

**퀴즈** 메뉴에서 독서 퀴즈를 만듭니다.

1. **"새 퀴즈"** 에서 **도서를 고릅니다.**
2. 저장하면 AI가 **우리 반 학년 눈높이에 맞는 4지선다 초안 문항을 자동으로 생성**합니다.
3. **편집 화면**에서 질문·보기·정답을 다듬습니다.
4. **"학생에게 게시"** 를 체크하면 학생에게 공개됩니다.

---

## 9. ⚙️ 루브릭 가중치 설정

**루브릭** 메뉴에서 우리 반의 **5축 채점 가중치(0~5)** 와 강조할 항목을 설정할 수 있습니다.
이 설정은 A/B/C 등급을 매길 때 반영됩니다. (예: "삶과 연결"을 더 중요하게 보고 싶다면 그 가중치를 높입니다.)

---

## 10. 🖨️ 문서 출력

### CSV 내보내기 (성적 데이터)

- 사이드바 **"CSV 내보내기"** 로 우리 반 독후감의 **사전·사후(고쳐쓰기) 5축 점수 + 향상도**를 엑셀에서 열 수 있는 CSV로 내려받습니다. (연구·대회 자료용)

### 인쇄물 4종

전용 인쇄 화면으로 아래를 뽑을 수 있습니다.

- 🏅 **표창장** (학생 최신 독후감 기반)
- ✉️ **가정통신문** (학생 전체 독후감 + 5축 평균)
- 📁 **독서 포트폴리오** (5축 방사형 + 뱃지)
- 📈 **학급 성장 리포트** (학급 전체 5축 평균)

> ℹ️ 인쇄물 4종은 사이드바에 링크가 없어, 랜딩 화면의 "문서 출력" 카드(CSV) 외에는 해당 인쇄 주소로 접근하는 형태입니다. 필요하면 관리자에게 인쇄물 링크 안내를 요청하세요.

---

## 11. 🔒 권한 경계 (할 수 있는 것 / 없는 것)

| 할 수 있는 것 ✅                    | 할 수 없는 것 ❌                   |
| ---------------------------------- | --------------------------------- |
| 우리 반 독후감 검토·승인·진위확인  | 다른 반 독후감 보기               |
| 우리 반 학생 추가·삭제·포인트 지급 | 다른 반 학생 관리                 |
| 우리 반 미션·퀴즈·루브릭 설정      | 학교 전체 통계(→ 교무관리자)      |
| 우리 반 문서 출력                  | 학생 독후감 대신 삭제 (기록 존중) |

> 학생의 독후감을 **대신 삭제하지 않습니다.** 교육 기록을 존중하는 설계예요. 삭제는 작성한 학생 본인만 할 수 있습니다.

---

## 🌟 정리 — 선생님의 하루 흐름

1. **로그인** → 선생님 콘솔 도착
2. **대시보드**에서 검토 대기·약점 확인
3. **검토** 메뉴에서 학생 독후감 첨삭 확인 → 점수 조정·코멘트 → **승인**
4. **학생관리**에서 계정·비밀번호·포인트 관리
5. **미션·퀴즈**로 활동 운영
6. 필요 시 **CSV·인쇄물**로 자료 출력

모든 작업은 **우리 반 안에서만** 이뤄지며, 승인이 학생의 게임 진행(진화·뱃지)에 꼭 필요하다는 점을 기억해 주세요. 📖
