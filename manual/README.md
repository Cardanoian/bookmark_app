# 📖 책갈피 역할별 사용 매뉴얼

「책갈피(Chaekgalpi)」를 사용하는 **5개 역할**별 안내서입니다.
각자 자신의 역할 문서를 열어, 로그인부터 주요 기능까지 순서대로 따라 하면 됩니다.

## 역할별 매뉴얼

| 역할 | 한 줄 소개 | 문서 |
|------|-----------|------|
| 🧒 **학생** | 독후감을 쓰고 몬스터를 키우며 게임처럼 독서하기 | [01-학생-매뉴얼.md](01-학생-매뉴얼.md) |
| 👩‍🏫 **담임 선생님** | 독후감 검토·승인, 학생·미션·퀴즈 관리 | [02-선생님-매뉴얼.md](02-선생님-매뉴얼.md) |
| 📚 **사서** | 인기 대출 집계, 이달의 책·행사 운영 | [03-사서-매뉴얼.md](03-사서-매뉴얼.md) |
| 🏫 **교무관리자(교무)** | 전교 통계 열람, NEIS 생기부 자동 요약 | [04-교무-매뉴얼.md](04-교무-매뉴얼.md) |
| 🛠️ **총괄관리자** | 학교·계정·콘텐츠 전체 운영 | [05-관리자-매뉴얼.md](05-관리자-매뉴얼.md) |

## 공통 — 로그인 빠른 안내

앱에 처음 들어가면 **"어떻게 로그인할까요?"** 안내 화면이 나옵니다.

| 구분 | 로그인 방법 | 로그인 후 도착 화면 |
|------|-------------|---------------------|
| 🧒 학생 | **🧒 학생 로그인** → 시·도 → 시·군·구 → 학교 → 반 → 이름 → 비밀번호 | 내 서재 (대시보드) |
| 👩‍🏫 담임교사 | **👩‍🏫 선생님 로그인** → 이메일 + 비밀번호 | 선생님 콘솔 |
| 📚 사서 | 선생님 로그인 (이메일) | 안내 화면 → `/librarian/dashboard` 로 이동 |
| 🏫 교무관리자 | 선생님 로그인 (이메일) | 안내 화면 → `/school_admin/stats` 로 이동 |
| 🛠️ 총괄관리자 | 선생님 로그인 (이메일) | 자동으로 `/admin` 콘솔 |

> ℹ️ **사서·교무관리자**는 로그인 첫 화면이 간단한 안내 화면이라, 실제 업무 화면 주소(`/librarian/dashboard`, `/school_admin/stats`)를 **북마크**해 두고 이용하세요. 자세한 내용은 각 매뉴얼을 참고하세요.

## 계정은 누가 만드나요?

| 역할 | 계정 발급 |
|------|-----------|
| 학생 | 담임교사가 6자 이상 비밀번호를 지정해 생성 |
| 교사 | 본인이 회원가입 (승인 없이 가입 즉시 로그인) |
| 사서·교무관리자 | 총괄관리자가 역할 부여 |
| 총괄관리자 | 시스템 세팅 / 기존 총괄관리자가 역할 부여 |
